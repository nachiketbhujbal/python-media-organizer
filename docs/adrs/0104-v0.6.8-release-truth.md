# ADR 0104: Record v0.6.8 release truth after publication

- Status: Proposed
- Date: 2026-09-12
- Applies: ADR 0090, ADR 0103

## Context

Version 0.6.8 was tagged from deliberately pre-publication documentation.
Current `main` documentation now needs a separate evidence-backed release-truth
reconciliation without moving or recreating the immutable tag.

## Proposed decision

Record the exact protected merge, exact-main gate, annotated tag, tag-triggered
release gate, reproducible artifact hashes, isolated installation, and installed
iMac command evidence. Promote the roadmap and changelog only after those facts
are verified.

## Consequences

- The immutable release tag remains fixed at the reviewed product merge.
- Current documentation distinguishes tagged source truth from the later
  release-status reconciliation.
- No package behavior or media collection changes in this documentation unit.
