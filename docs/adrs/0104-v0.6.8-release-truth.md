# ADR 0104: Record v0.6.8 release truth after publication

- Status: Accepted
- Date: 2026-09-12
- Applies: ADR 0090, ADR 0103

## Context

Version 0.6.8 was deliberately tagged from a source tree whose changelog and
roadmap still described it as an unreleased candidate. That statement was true
before publication and preserved the release boundary required by ADR 0090.

The release has now crossed its protected publication boundary. Current
documentation on `main` should record the completed facts without changing the
immutable release tag.

The final owner head is
`55a24cf7be02dc15c6fc91f7c6be04a74dea2a2b`. PR #62 full-platform run
`34724550036` passed and merged through the protected merge-commit path as
`07b250689332b1cb8d453aa578191bf75a253b5a`. Exact-main run `34724753050`
passed the same platform set and unconditional quality gate before annotated
tag `v0.6.8` was created. Tag object
`991d04f70b1c94036a12d93fde71958f065513c8` peels to that merge, and
tag-triggered release run `34724948262` passed.

A fresh detached tagged build produced wheel SHA-256
`4b7f311c9b86f4fc450c006891283715e999decc56d55a6bec5a3241e0785e69`
and source-distribution SHA-256
`b0081faa7aa8cacde761a490b5c8acf5ffa326145c1880cc9ed7f02e27686ed9`.
The artifacts carry version 0.6.8, use safe relative members, and package the
repository Apache-2.0 license exactly. An isolated tagged-wheel installation
reported `pymo 0.6.8` and exposed both duplicate-disposition selectors. The
iMac's uv-managed command also reports `pymo 0.6.8`.

## Decision

Use a separate documentation-only pull request after the v0.6.8 tag to record
the release evidence and promote the roadmap entry from release candidate to
released.

The reconciliation does not move or recreate v0.6.8, alter package behavior,
or begin v0.6.9 implementation. The tagged source remains an accurate snapshot
of the pre-publication candidate state; the later `main` documentation is the
authoritative current release-status view.

## Consequences

- V0.6.8 release claims remain limited to observed publication evidence.
- Independent exact-SHA review accepted the implementation and final
  review-ledger delta without findings.
- Synthetic installed acceptance exercised retained-in-place disposition; no
  retained private collection or rollback evidence was touched before release.
- The immutable tag remains fixed at the reviewed product release merge.
- Version 0.6.9 requires its own claim, branch, worktree, ADR, implementation,
  review, and release boundary.
