# ADR 0094: Record v0.6.3 release truth after publication

- Status: Accepted
- Date: 2026-09-11
- Applies: ADR 0090

## Context

Version 0.6.3 was deliberately tagged from a source tree whose changelog and
roadmap still described it as an unreleased candidate. That statement was true
before publication and preserved the release boundary required by ADR 0090.

The protected merge, exact-main quality gate, annotated tag, tagged build and
isolated-install workflow, independent local tagged build and resume
acceptance, and installed iMac command have now been observed. Current
documentation on `main` should record those completed facts without changing
the immutable release tag.

## Decision

Use a separate documentation-only pull request after the v0.6.3 tag to record
the release date, promote the roadmap entry from release candidate to released,
and add the exact release evidence to the handoff and review ledger.

The reconciliation does not move or recreate v0.6.3, alter package behavior,
or begin v0.6.4 implementation. The tagged source remains an accurate snapshot
of the pre-publication candidate state; the later `main` documentation is the
authoritative current release-status view.

## Consequences

- V0.6.3 release claims are backed by observed merge, CI, tag, build, resume,
  and installed-version evidence.
- The immutable tag remains fixed at the reviewed product release merge.
- Version 0.6.4 requires its own claim, branch, worktree, ADR, implementation,
  review, and release boundary.
