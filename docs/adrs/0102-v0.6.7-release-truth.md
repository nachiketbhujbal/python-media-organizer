# ADR 0102: Record v0.6.7 release truth after publication

- Status: Accepted
- Date: 2026-09-12
- Applies: ADR 0090, ADR 0101

## Context

Version 0.6.7 was deliberately tagged from a source tree whose changelog and
roadmap still described it as an unreleased candidate. That statement was true
before publication and preserved the release boundary required by ADR 0090.

The release has now crossed its protected publication boundary. Current
documentation on `main` should record the completed facts without changing the
immutable release tag.

The final owner head is
`d07acffe5befae5f202b61f7d0c3df8bd70d13cb`. PR #60 full-platform run
`34715221308` passed and merged through the protected merge-commit path as
`eac3a94a6d298ea87b56e470f106d7f3bb25746c`. Exact-main run `34715467561`
passed the same platform set and unconditional quality gate before annotated
tag `v0.6.7` was created. Tag object
`e489836f597d08398cefb95d4eecc69b9090f23c` peels to that merge, and
tag-triggered release run `34715686329` passed.

A fresh detached tagged build produced wheel SHA-256
`fad2c9b5fe9e5b57bc42f8dc585c122dc1abc085efe2eb676f0e8813912aefbc`
and source-distribution SHA-256
`fff46b1390ee3fdbcecbea00692c2b3b9fbe0b77594beab69704592fd4bfc641`.
The artifacts carry version 0.6.7, pass the packaged-member safety checks, and
package the repository's Apache-2.0 license exactly. An isolated tagged-wheel
check confirmed full, private, and quiet output; clean profiled help; and
migration profile recovery through explicit resume. The iMac's uv-managed
command reports `pymo 0.6.7`.

## Decision

Use a separate documentation-only pull request after the v0.6.7 tag to record
the release evidence and promote the roadmap entry from release candidate to
released.

The reconciliation does not move or recreate v0.6.7, alter package behavior,
or begin v0.6.8 implementation. The tagged source remains an accurate snapshot
of the pre-publication candidate state; the later `main` documentation is the
authoritative current release-status view.

## Consequences

- V0.6.7 release claims remain limited to observed publication evidence.
- Synthetic installed acceptance is proportionate to this output-policy-only
  change; no retained private media collection or rollback evidence was
  touched.
- The immutable tag remains fixed at the reviewed product release merge.
- Version 0.6.8 requires its own claim, branch, worktree, ADR, implementation,
  review, and release boundary.
