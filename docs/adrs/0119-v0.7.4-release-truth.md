## Decision

Reconcile current release records in a separate documentation-only pull request
without moving the immutable tag. Explicit recovery is released; v0.7.5 aggregate
synopsis remains next. The promoted sequence ends at a production-readiness
reassessment, not automatic permission for migration or source retirement.

## Limits

Recovery retains exact version, policy, roots and strict state bindings. It
refuses ambiguous partial children, unresolved journals and failed mutations;
failed read retries require deliberate selection. Unsigned terminal manual runs
require fresh verification and human review. Completed records are historical,
not new preservation evidence. This release performs no initial rescue copying,
cleanup, concurrency, real collection trial, workbook operation or PyPI publication.
