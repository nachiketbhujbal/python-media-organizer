# ADR 0107: Record v0.6.9 release truth after publication

- Status: Accepted
- Date: 2026-09-13
- Applies: ADR 0090, ADR 0105, ADR 0106

## Context

Version 0.6.9 was deliberately tagged from a source tree whose changelog and
roadmap still described it as an unreleased candidate. That statement was true
before publication and preserved the release boundary required by ADR 0090.

The release has now crossed its protected publication boundary. Current
documentation on `main` should record the completed facts without changing the
immutable release tag.

Independent Terra-medium review accepted exact final implementation head
`2388d5811cb8ae1708bfd4023fd6227fa7012b33` without findings. PR #65
full-platform run `34781201431` passed and merged through the protected
merge-commit path as `2d24cc4afb631ab154e293605caee9b5ec867e4f`.
Exact-main run `34781522839` passed the same platform set and unconditional
quality gate before annotated tag `v0.6.9` was created. Tag object
`a4571f5acff7fe7eb75a711556b55e589f9c0f11` peels to that merge, and
tag-triggered release run `34781773024` passed.

A fresh detached tagged build produced wheel SHA-256
`a6d82305f17df9b58cf4617d7f65181daf7d3713efd5480470b2123b6ca47d76`
and source-distribution SHA-256
`a5dc3e2fae4712cacce725455ee5786c4ec09aec3fee3bc2a668f326bad36c46`.
The artifacts carry version 0.6.9 and use safe relative members. An isolated
tagged-wheel installation previewed, applied, verified, previewed undo, and
atomically restored a synthetic retained tree with exact SHA-256 agreement and
no absolute paths or filenames in the collection journal. The iMac's
uv-managed command reports `pymo 0.6.9`.

## Decision

Use a separate documentation-only pull request after the v0.6.9 tag to record
the release evidence, promote the roadmap entry from release candidate to
released, and close the version 0.6 operator-experience sequence.

The reconciliation does not move or recreate v0.6.9, alter package behavior,
or begin v0.7.0 implementation. The tagged source remains an accurate snapshot
of the pre-publication candidate state; the later `main` documentation is the
authoritative current release-status view.

## Consequences

- V0.6.9 release claims remain limited to observed publication evidence.
- Same-filesystem managed quarantine is reversible retained storage; it does
  not copy, delete, or reclaim physical storage.
- Cross-filesystem managed quarantine begins separately in version 0.7.0.
- Synthetic installed acceptance was sufficient for this bounded release; no
  retained private collection or rollback evidence was changed or removed.
- The immutable tag remains fixed at the reviewed product release merge.
