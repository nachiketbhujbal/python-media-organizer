# ADR 0100: Record v0.6.6 release truth after publication

- Status: Accepted
- Date: 2026-09-12
- Applies: ADR 0090

## Context

Version 0.6.6 was deliberately tagged from a source tree whose changelog and
roadmap still described it as an unreleased candidate. That statement was true
before publication and preserved the release boundary required by ADR 0090.

The release has now crossed its protected publication boundary. Current
documentation on `main` should record the completed facts without changing the
immutable release tag.

The final owner head is
`00c852264f0aa89c4e9bbc6d111413f9cb7c7278`. PR #58 passed its full hosted
gate and merged through the protected merge-commit path as
`75bf41788297fc48570952d675f4af3e1d9ce8dd`. The exact merge passed the
separate full `main` gate before annotated tag `v0.6.6` was created. Tag object
`32903f38eee561bedfe0a7a92d8cada74ba5a561` peels to that merge, and the
tag-triggered release workflow passed.

A fresh detached tagged build produced wheel SHA-256
`d5912bb1863fbcbd8b6c6620f412cae18747702228f5c1b4af91865a739394de`
and source-distribution SHA-256
`22785b3b78342d5cfdfcb176f140b640294b01684c5f3da58ba1eb74396e1378`.
The artifacts carry version 0.6.6, contain no unsafe member names, and package
the repository's Apache-2.0 license exactly. An isolated tagged-wheel check
confirmed independent console and file thresholds plus owner-only diagnostic
file permissions. The iMac's uv-managed command reports `pymo 0.6.6`.

## Decision

Use a separate documentation-only pull request after the v0.6.6 tag to record
the release evidence and promote the roadmap entry from release candidate to
released.

The reconciliation does not move or recreate v0.6.6, alter package behavior,
or begin v0.6.7 implementation. The tagged source remains an accurate snapshot
of the pre-publication candidate state; the later `main` documentation is the
authoritative current release-status view.

## Consequences

- V0.6.6 release claims remain limited to observed publication evidence.
- Synthetic installed acceptance is proportionate to this logging-only change;
  no retained private media collection or rollback evidence was touched.
- The immutable tag remains fixed at the reviewed product release merge.
- Version 0.6.7 requires its own claim, branch, worktree, ADR, implementation,
  review, and release boundary.
