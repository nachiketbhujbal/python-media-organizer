# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities through GitHub's private
vulnerability reporting for this repository. Do not open a public issue for a
security report.

Do not include private media, collection names, private filesystem paths,
identifying metadata, action logs, cache databases, or unreviewed command logs.
Use a minimal synthetic reproduction whenever possible. Include the affected
`pymo` version, operating system, impact, and the smallest steps needed to
reproduce the issue safely.

The maintainer will acknowledge a usable report, investigate it privately, and
coordinate disclosure after a fix or documented mitigation is ready. No
response-time guarantee is made.

## Supported versions

This project is pre-1.0. Security fixes are made on the current release line;
older versions may require upgrading to receive a fix.
